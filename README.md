# TOY_HUDとは

TOY_HUDは、本家HUD SIGHTが手に入らないけどHUDサイト体験をしたかったサークル主がどうにかこうにか作成した超簡易HUDサイトです。
照準器としての性能はゼロですが、「投影されるHUD表示を覗く」、「姿勢にHUD表示が追従」等のHUDサイト体験ができるようになっています。
誰でも改変・アレンジできるように、プログラムや3Dプリントデータを公開しています。

---

## ファイル構成

・TOY_HUD_software.ino
  TOY HUD内のSeeeduino XIAO MG24 Sense に書き込むArduinoスケッチです。
  Seeeduino社の入門ガイドwikiを参考に書き込んで使用ください。→ https://wiki.seeedstudio.com/ja/xiao_mg24_getting_started/
  
・TOU_HUD_側面パネル.3mf
  TOY HUDの側面パネルの3Dプリントデータです。BambuLab製プリンター向けのファイルです。
